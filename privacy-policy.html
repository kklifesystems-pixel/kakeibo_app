「予定&家計コントロール」（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報および利用データを適切に取り扱います。本ポリシーは、本アプリがどのような情報を収集・利用・保存するかを説明するものです。

1. 収集する情報

本アプリは、機能の提供に必要な範囲で以下の情報を取り扱います。

  • 家計簿・予定データ … 収支、予定、カテゴリ、メモ、目標設定など（ユーザーが入力した内容）
  • 端末内設定 … 言語、テーマ色、通知設定など
  • Google アカウント情報 … Google 連携を利用する場合、メールアドレスおよび Google カレンダー・Google Drive（アプリ専用領域）へのアクセス
  • Firebase（Google Cloud） … ユーザーがクラウド同期を有効にした場合、Firebase Firestore に世帯共有データが保存されます
  • カメラ・画像 … レシート読み取りおよび家族共有の QR コード読み取り時（端末内で処理し、画像自体はサーバーに送信しません）
  • 広告関連データ … Google AdMob による広告表示時（広告識別子など。Google のポリシーに従います）

2. 情報の利用目的

  • 家計簿・予定管理機能の提供
  • Google カレンダーとの連携、クラウドバックアップ、世帯共有（QR ペアリング後、Firestore で家計・予定を共有。ユーザーが有効にした場合）
  • 予定リマインダー通知の送信
  • レシートからの金額読み取り（端末内 OCR）
  • 広告の表示（無料版）
  • アプリの改善・不具合対応

3. 情報の保存場所

  • 端末内 … 家計簿・予定データの多くは端末内（SharedPreferences）に保存されます
  • Google Drive … ユーザーがバックアップを実行した場合、アプリ専用の非公開領域に保存されます
  • Firebase Firestore（Google Cloud） … ユーザーがクラウド同期を有効にした場合、世帯共有データが保存されます
  • 手動バックアップ … ユーザーがエクスポートした JSON ファイルは、ユーザー自身が管理します

運営者が独自のサーバーに家計データを保存することはありません（Google API 利用を除く）。

4. 第三者への提供

運営者は、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に販売しません。以下のサービス提供者と、機能提供に必要な範囲でデータが共有される場合があります。

  • Google LLC（Google サインイン、Google カレンダー、Google Drive）
  • Google LLC（Firebase Firestore — 世帯共有のクラウド同期を有効にした場合）
  • Google LLC（Google AdMob 広告サービス）

各サービスのプライバシーポリシー:

  • Google プライバシーポリシー

5. 権限について

  • インターネット … API 連携・広告表示
  • カメラ … レシート撮影
  • 通知 … 予定リマインダー
  • 正確なアラーム … 指定時刻のリマインダー（利用できない端末では代替方式を使用）

権限は、該当機能を利用する際に説明を表示したうえでリクエストします。

6. データの削除

  • アプリを端末から削除すると、端末内に保存されたデータは削除されます
  • Google Drive 上のバックアップは、Google アカウント設定またはアプリ内の復元機能から管理できます
  • データ削除のご依頼は、下記お問い合わせ先までご連絡ください

7. お子様のプライバシー

本アプリは、13 歳未満のお子様を対象としていません。13 歳未満の方から故意に個人情報を収集することはありません。

8. セキュリティ

運営者は、合理的な範囲でデータの保護に努めます。ただし、インターネット上の通信および端末内保存には完全な安全性を保証できません。バックアップファイルには家計データが含まれるため、第三者と共有しないでください。

9. ポリシーの変更

本ポリシーは、必要に応じて改定することがあります。重要な変更がある場合は、アプリ内または本ページでお知らせします。改定後も本アプリを利用された場合、変更に同意したものとみなします。
